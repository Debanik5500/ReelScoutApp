# Kept

Share a reel. Kept pulls out what matters — the gist, the key moments, anything
worth remembering, and a place if there is one — so you don't lose it in your
camera roll or a pile of old DMs.

Kept is a SwiftUI iOS app built around one idea: **there is no "add reel" button
in the app.** The only way a reel enters your library is by sharing it in from
Instagram (or anywhere else) via the iOS share sheet. Everything else — the
summary, the key frames, the location, the board it belongs to — is decided by
the backend and then can be corrected by you if it got something wrong.

## What's here

- **Library** — a grid of everything you've kept, with boards Kept has grouped
  automatically, a Favorites row, live search, and category filters.
- **Live processing** — share a reel and watch it get read in real time: a
  blurred cover that sharpens step by step, a progress ring, and a status
  label, right there in the grid and on a dedicated detail screen.
- **Reel detail** — the gist, a swipeable stack of key moments, a checklist of
  "worth remembering" points, a map card if a location was found, and a link
  to the board it's part of.
- **Edit** — every extracted field is correctable: title, author, category,
  the gist, each remembered point, and the location (name, neighborhood, map
  link). This is the only editing surface in the app, by design.
- **Shuffle** — a slanting swipeable stack through your saved reels.
- **Places** — every location Kept has found, in one list.
- **Share Extension** — a storyboard-free iOS share extension that hands a
  shared URL off to the host app via an App Group + a custom URL scheme
  (`kept://share?url=...`), so it works whether or not the app is already
  running.

## Status

The backend is fully mocked right now (`MockReelService` + a `Timer`-driven
state machine in `ReelStore`), seeded with a handful of boards and reels so
the UI has something to show. Swapping in a real backend means writing a new
`ReelService` conformance — no view code should need to change.

**Known gaps, not yet done:**
- Instrument Serif / Geist are referenced by name in `Theme.swift` but the
  actual font files aren't bundled yet (no `UIAppFonts` entry either).
- Map pins use placeholder coordinates rather than geocoding the real
  `mapURL` on a `ReelPlace`.
- No real App Icon image (the asset slot is a placeholder).
- `project.pbxproj` and the Xcode schemes under `xcshareddata/xcschemes/`
  were hand-written rather than generated by Xcode/XcodeGen (there was no
  Xcode toolchain available in the environment this was built in). They've
  been validated for structural correctness but the usual Xcode-generated
  guardrails don't apply, so treat unusual build-setting issues as a reason
  to check the project file first.

## Running it

Open `ReelScoutApp.xcodeproj` in Xcode, pick the **ReelScoutApp** scheme (not
ShareExtension — that one only runs embedded in the host app), choose any
iOS 17+ Simulator, and hit Run. Both targets are set to automatic code
signing with no team configured, so Simulator builds need nothing extra; a
physical device needs a Development Team set in Signing & Capabilities for
both targets.

To exercise the share flow without a real Instagram reel, open Safari in the
Simulator and navigate to:

```
kept://share?url=https://instagram.com/reel/test123
```

That drives the same `onOpenURL` path the real share extension uses.

## Project layout

```
App/            App entry point, root tab view, URL-scheme handling
Core/           Design tokens (Theme), App Group bridge
Domain/         Reel, Board, KeyMoment, KeepPoint, ReelPlace models
Services/       ReelStore (source of truth), MockReelService (seed data + sim)
Components/     Reusable views: PinCard, LiveProcessingCard, SwipeStack
Features/       One folder per screen: Library, Reel, Processing, Saved,
                Board, Places, Edit
ShareExtension/ The iOS share extension target
Assets.xcassets Cover art for seeded reels, app icon, accent color
```

## Requirements

- Xcode 15+, iOS 17+ deployment target, Swift 5.9
- No third-party dependencies — pure SwiftUI + Combine
